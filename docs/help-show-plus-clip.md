# Show+ — save the last 30 seconds (⏮ CLIP)

## What it is

While Show+ has a camera open it keeps the **last 30 seconds** of the host camera. **⏮ CLIP** saves them as a
**.webm** video file.

## When to use it

Something great just happened on camera and you want it for social media or a replay.

## Save a clip

1. Press **⏮ CLIP**.
2. Choose where to save the file and press **Save**.
3. Open the file in any browser or VLC.

The clip is the last 30 seconds up to the press, however long Show+ has been open. (Before this fix, a clip saved after
the first 30 seconds was missing the file's header and would not play.)

## Good to know

- The clip is the host camera only, not the full composited program. For the program, use **Record**.
- Cancel in the Save window saves nothing.
